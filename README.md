**Currently a work in progress**

A SoapySDR wrapper for Swift. Provides a convenient API surface for controlling & getting samples from a wide variety of SDRs. 

I built this to make SwiftAIS and SwiftDSC work with more than just RTL-SDR.

It doesn't implement all of SoapySDR. In particular, I completely ignored Tx for now, and don't plan on implementing it because I have no SDR with which to test it.
